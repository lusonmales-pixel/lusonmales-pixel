### Projects

- ***Alpine Password Manager.*** A password manager with a Zero Knowledge architecture, written entirely in Go. The Argon2, AES-GCM, and HKDF encryption protocols were used. The project is entirely backend-based. A frontend for this project will be written soon.

- ***odeshell.*** A small tutorial shell in C++17 that demonstrates how to implement a simple command interface and work with the file system via `std::filesystem`. This is not a full-fledged POSIX shell, but rather a learning project.

- ***OdemaVPN.*** Lightweight Go backend for automating VPN subscriptions through Telegram, integrating 3X-UI/Xray, VLESS, Lava Payments and PostgreSQL. Handles user authentication, VPN provisioning, payments, subscription renewals, referrals and automatic expiration.
